# Zomato-Restaurant-Data-Analysis-SQL

## Overview

An SQL-based analysis of Zomato restaurant data to uncover insights into restaurant ratings, pricing, locations, cuisines, online ordering, and customer preferences.

## Key Analysis

* Analyzed restaurant performance using advanced SQL queries.
* Identified top-performing locations, cuisines, ratings, and pricing trends.
* Used aggregations, joins, subqueries, CTEs, window functions, and ranking techniques.

## Tools

**SQL Server | Microsoft SQL Server Management Studio | Excel**

## Dataset

Zomato Restaurant Dataset from Kaggle.
